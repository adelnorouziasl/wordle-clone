# Wordle Clone

A Wordle-inspired word guessing game built with vanilla HTML, CSS, and JavaScript.

## How to Play
- Guess the 5-letter word in 6 tries
- Green = correct letter, correct spot
- Yellow = correct letter, wrong spot
- Gray = letter not in the word
- The diagonal split tile is a unique mechanic — it means the letter is in the correct spot, but there's still another copy of that letter elsewhere in the word you haven't found yet

## Features
- NYT Wordle word lists for answers and valid guesses
- Flip, bounce, and shake animations
- Win streak tracking
- Game state saved on refresh
- Mobile responsive

## Built With
- HTML, CSS, JavaScript (no frameworks)
